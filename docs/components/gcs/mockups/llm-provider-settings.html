Provider Settings

Editing selected provider

Selecting Edit in the provider list loads that provider into this form. Save updates the existing provider. New Provider clears the form for a new record.

Templates are optional shortcuts for common provider defaults. Choose one to pre-fill the form, or keep Custom / OpenAI-compatible for providers not listed here. Saving still happens only with Save Provider.

JSON Tab Integration

Scoped Import / Export

Preview before apply

The JSON tab should export or import selected settings sections. Missing sections in a loaded file are ignored by default, so loading an older connectivity-only file does not erase LLM providers or routing rules.

Export sections

Import behavior

llm_providers and model_routing are separate JSON sections, so provider setup can be restored without forcing routing changes.

Secret handling should export environment variable names and masked secret references, not plaintext API keys.
